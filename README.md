# Brain Bubble Pop

🏆 **1st Place Winner — Anthropic Claude AI Hackathon**

A single-file browser game for study breaks — pop bubbles to de-stress, built around a study/break timer.

## Play it

Just open [`app.html`](./app.html) in any browser. No build step, no dependencies.

## Features

- Study/break timer (Pomodoro-style)
- Bubble popping with sound effects, particle bursts, and combo tracking
- Bomb bubbles to avoid
- Score and high score tracking
